# Johanna Ye — Pianist

Personal website for pianist Johanna Ye: biography, concerts, gallery, and contact.

Static site (HTML/CSS/vanilla JS), styled in the spirit of elimchan.nl. Deployed via GitHub Pages.

## Structure

- `index.html` — homepage / hero
- `about.html` — biography
- `concerts.html` — upcoming & past performances
- `gallery.html` — photos and recordings
- `contact.html` — contact info
- `css/style.css` — shared stylesheet
- `js/main.js` — nav behavior
- `images/` — photos

## Updating concert dates

Edit `concerts.html` — each performance is a `<li class="concert-item">` block; see the
comment near the top of the file for the exact markup to copy.
